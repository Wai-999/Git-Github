# 🌿 Git & GitHub — Two Sites, One Goal

**Start here (beginners):** https://wai-999.github.io/Git-Github/
**Full reference:** https://wai-999.github.io/Git-Github/reference.html

Learn Git and GitHub from absolute zero, then keep the reference open forever. Both run in any browser on Mac, Windows, or mobile — no installation, works offline.

## 🌱 `index.html` — Git for Beginners

A guided 14-step course, one idea per screen, in plain language with pictures.

- No jargon, no prerequisites, about 25 minutes
- One running metaphor: Git is saving your progress in a video game
- Interactive: a click-through save-point machine, a "what went wrong?" fixer, check-yourself questions, and a final quiz
- Remembers where you stopped

## 📘 `reference.html` — Full Reference

The complete technical guide, 8 chapters:

Foundations · The Command Line · Git Fundamentals · Branching & Remotes · Collaboration & Safety · Professional Practice · Your First Real Project · Reference & Quiz

- Two simulators — an add→commit→push machine and a working bash terminal playground
- 10+ infographics — the map of Git commands, commit anatomy, merge vs rebase, PR lifecycle, undo decision tree
- Searchable cheat sheet, glossary, quiz, light/dark theme, printable to PDF

## Run locally

Download both files into the same folder and double-click `index.html`. Everything is embedded — no internet needed.
